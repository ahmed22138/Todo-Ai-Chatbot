# 📋 Todo AI Chatbot - User Guide

Complete guide for using your AI-powered task management chatbot.

---

## 🎯 Overview

Todo AI Chatbot is an intelligent assistant that helps you manage your tasks using natural language. No need to remember commands - just talk naturally!

---

## 🚀 Getting Started

### 1. **Sign Up / Login**
- Open the application
- Create an account or login with existing credentials
- You'll be redirected to the chat interface

### 2. **Start Chatting**
- Simply type your message in the input box
- Press Enter or click the send button
- The AI will understand and help you!

---

## 📝 How to Use - Task Management

### ✅ **Adding Tasks**

Talk naturally about what you want to add:

```
Examples:
• "add buy groceries"
• "create a task to call mom"
• "I need to finish the report by Friday"
• "remind me to pay bills"
• "add task: workout at gym"
```

**What happens:** The AI will create a new task for you and confirm it.

---

### 📋 **Listing Tasks**

Ask to see your tasks in various ways:

```
Examples:
• "show my tasks"
• "list all tasks"
• "what do I need to do?"
• "show incomplete tasks"
• "show completed tasks"
• "what's on my todo list?"
```

**What happens:** The AI will display your tasks with their current status.

---

### ✓ **Completing Tasks**

Mark tasks as done:

```
Examples:
• "mark buy groceries as complete"
• "I finished the report"
• "complete task 1"
• "mark first task as done"
• "I did the workout"
```

**What happens:** The AI will mark the specified task as complete.

---

### ✏️ **Updating Tasks**

Modify existing tasks:

```
Examples:
• "update task 1 to buy milk and bread"
• "change the grocery task to buy vegetables"
• "edit the first task"
• "update my workout task to yoga session"
```

**What happens:** The AI will update the task with new details.

---

### 🗑️ **Deleting Tasks**

Remove tasks you don't need:

```
Examples:
• "delete the grocery task"
• "remove task 2"
• "delete buy groceries"
• "remove the first task"
• "I don't need the workout task anymore"
```

**What happens:** The AI will delete the specified task.

## 💬 Sample Conversations

### Conversation 1: Daily Tasks
```
You: add buy groceries

You: also add call dentist

You: show my tasks

    1. Buy groceries (incomplete)

AI: Got it! Added "finish project report by Friday" to your list.

You: add review code
AI: Done! Added "review code" to your tasks.

You: delete the bill task, I already paid it
AI: Removed "pay electricity bill" from your tasks.

AI: Added! "Workout at gym" is now on your list.
```

## ❓ Frequently Asked Questions

### Q1: Can I use Hindi/Urdu?
**A:** Yes! The AI understands English, Hindi, Urdu, and Hinglish.

### Q2: How do I reference a specific task?
**A:** Use task number (task 1), position (first task), or task name (grocery task).

### Q3: Can I see only incomplete tasks?
**A:** Yes! Say "show incomplete tasks" or "what's pending?"

### Q4: How do I start a new conversation?
**A:** Click the "New Conversation" button in the header.

### Q5: Are my tasks private?
**A:** Yes! Each user has their own private task list.

### Q6: Can I edit a task after creating it?
**A:** Yes! Use "update task X to [new description]"

### Q7: What if I make a mistake?
**A:** Just tell the AI! "delete the last task" or "undo that"
